# Prévia estática

Estas imagens mostram uma composição aproximada do conteúdo real do README em fundo claro, escuro e largura de celular. Foram renderizadas localmente, não capturadas no GitHub.

O bloco Lado B aparece fechado. No README real, ele é um elemento HTML `details` que pode ser aberto. O renderizador estático não executa essa interação; o comportamento não foi testado em um navegador nesta entrega.

As proporções dos gráficos são preservadas. A fonte, o espaçamento e a quebra de linha do texto nativo podem variar no GitHub.
